# ai-rule-based-chatbot-task-1
Developed a Rule-Based Chatbot using Python that simulates basic human conversation through keyword-based intent recognition and predefined response rules. The chatbot handles greetings, admission inquiries, course information, fee-related questions, and user interactions through a command-line interface.
## Project Overview

This project is a Rule-Based Chatbot developed using Python. The chatbot interacts with users by identifying keywords in their input and responding with predefined answers. It demonstrates the fundamentals of conversational AI, rule-based decision making, and natural language processing concepts.

### Features
- User-friendly command-line interface
- Greeting and farewell responses
- Course information assistance
- Admission-related query handling
- Fee information support
- Keyword-based intent recognition
- Continuous conversation until user exits

### Technologies Used
- Python 3
- Conditional Statements
- Loops
- String Processing

### Learning Outcomes
- Understanding chatbot architecture
- Implementing rule-based AI systems
- Handling user input and responses
- Developing interactive Python applications
